Mono-depth AI → point cloud + mesh + floor-plan, fully offline.

Our build · fallback + R2
In one line: our own pipeline — estimate depth from each video frame with an AI model, fuse into a 3D point cloud + mesh + floor-plan, all offline on your laptop. Not photorealistic, but it's ours end-to-end and it already runs.

100% offline on your laptop. Uniquely also outputs an occupancy grid + floor-plan — the seed of Round-2 navigation.

How it works, step by step

  • Split the phone video into frames.
  • Depth Anything V2 predicts a depth map for every frame (metric indoor model → real metres).
  • Back-project + fuse the depths into one metric point cloud (~3.9 M points) with a camera path.
  • Build a Poisson mesh, detect planes, and rasterise a floor-plan + 3D occupancy grid.
  • View the colored cloud / mesh in the browser (and, for Round 2, the floor-plan for pathfinding).

Trade-offs

✓ Strengths

  • Fully offline — no cloud, no account, private
  • Our own code — strongest 'pipeline soundness' story
  • Outputs a floor-plan + occupancy map (nav-ready)

✗ Weaknesses

  • Not photorealistic — mono-depth is noisy
  • Poisson mesh looks webby / imperfect
  • Needs the 4 GB GPU (Smart App Control sometimes blocks it)
